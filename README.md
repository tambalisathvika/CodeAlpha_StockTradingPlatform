# Stock Trading Platform

## Description
A Java Swing based Stock Trading Platform that simulates stock market trading.

## Features
- Live Market Data Display
- Buy Stocks
- Sell Stocks
- Portfolio Management
- Transaction History
- Watchlist
- Revenue / Analytics
- File Storage using portfolio.txt
- Transaction Persistence using transactions.txt

## Technologies Used
- Java
- Swing GUI
- OOP Concepts
- File Handling
